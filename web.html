Website built from scratch with HTML, CSS and JavaScript.

For this project, we were to create a landing page for a brand of our choice. I chose the makeup brand "Flower Knows" and I made a visually aesthetic page with animations, carousels and a consistent navigation.

Even though this project looks quite simple, it took me a while to figure out the JavaScript animations and to get them to behave right. For future reference I want to learn more JavaScript as I do think it makes a website so much more elevated.
